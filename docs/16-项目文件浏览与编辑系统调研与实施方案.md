# 项目文件浏览与编辑系统 — 调研与实施方案

> 日期：2026-07-27
>
> 目标：在项目 workspace 中新增「文件」tab，实现远程/本地项目的目录树浏览、
> 文件内容查看与编辑功能，让用户能在 Web 界面直接查看和修改项目文件。
>
> 决策摘要：
> - 文件树组件选用 **react-complex-tree**（原生异步懒加载、零依赖、16.9KB gzip）
> - 文件查看选用 **prism-react-renderer**（只读语法高亮、~5KB gzip）
> - 文件编辑选用 **CodeMirror 6**（懒加载，按需 dynamic import）
> - 后端新增 `/api/projects/{id}/fs/*` REST API，统一本地/远程文件操作
> - SFTP 改为持久化 session，避免每次新建 client 的握手开销
> - MVP 不实现文件监听，采用手动刷新 + tab 切换刷新 + run 完成自动刷新
> - 并发安全策略：读始终允许，写需 workspace lease（运行时只读模式）
>
> 非目标：
> - 不实现完整 IDE（不集成 code-server / Eclipse Theia）
> - 不实现终端/Shell 访问
> - 不实现协作编辑（多用户同时编辑同一文件）
> - 不实现文件监听（inotifywait / fsnotify），延后至后续版本
> - 不实现 VS Code 扩展级别的智能补全（IntelliSense）

## 1. 问题背景

### 1.1 现状

当前项目加载后，用户只能在「对话」tab 中通过自然语言与 Claude Code 交互，由 AI 执行文件操作。用户无法：

- **查看项目目录结构**：不知道项目中有哪些文件和目录
- **查看文件内容**：无法直接阅读源码、配置文件
- **手动编辑文件**：所有修改必须通过 AI 对话，无法直接编辑

唯一的文件相关能力是 `ImportProjectPage` 中的目录选择器（仅展示目录，用于选择项目路径）和 `GitWorkbench` 中的 diff 查看（仅展示 Git 变更差异）。

### 1.2 需求

用户需要在 Web 界面中：

1. **浏览项目目录树**：展开/折叠文件夹，查看文件列表
2. **查看文件内容**：带语法高亮的只读查看
3. **编辑文件**：对文本文件进行修改并保存
4. **创建/删除/重命名文件**：基本的文件操作
5. **查看非文本文件**：图片预览、二进制文件元信息

### 1.3 约束

- **本地项目**：文件通过本地文件系统（Go `os` 包）访问
- **远程项目**：文件通过 SSH/SFTP 访问，受 `rootPath` 沙箱限制
- **并发安全**：Claude Code 运行时持有 workspace lease，文件写入操作需互斥
- **性能**：远程文件操作延迟高（SFTP 每次请求 50-200ms），需懒加载
- **移动端**：项目已有 820px/680px/520px 响应式断点体系

## 2. 技术方案对比

### 2.1 文件树组件

| 组件 | react-arborist | react-complex-tree | 自研方案 |
| --- | --- | --- | --- |
| 版本 | 3.16.0 | 2.6.2 | — |
| 周下载量 | 696K | 183K | — |
| 最后更新 | 2026-07-25 | 2026-06-24 | — |
| **异步懒加载** | ❌ 不支持 | ✅ 原生支持 | 自定义 |
| React 19 兼容 | ⚠️ 有风险 | ✅ 安全（零依赖） | ✅ 完全兼容 |
| Bundle (gzip) | 31.6KB | 16.9KB | 按需 |
| 运行时依赖 | react-dnd, redux, react-window | **零** | — |
| 虚拟化 | 有 | 无 | 可选 |
| 拖拽排序 | 有（react-dnd） | 有（自研） | 可选 |
| 内联重命名 | 有 | 有 | 自定义 |
| TypeScript | 是 | 是 | 是 |

**react-arborist 的致命缺陷：**

1. **不支持异步懒加载**：数据模型要求一次性传入完整树结构。`onToggle` 只是回调，无异步加载子节点机制。远程文件树必须懒加载——点击文件夹才加载子内容，一次性加载整个目录树对大项目不可接受
2. **依赖已废弃的 react-dnd**：react-dnd 最后更新 2022-04-19（4 年+未维护），在 React 19 Strict Mode 下存在未验证风险

**react-complex-tree 的核心优势：**

- `TreeDataProvider` 接口原生支持异步：`getTreeItem(itemId): Promise<TreeItem<T>>`
- `onExpandItem` 回调触发异步加载，`onMissingItems` / `onMissingChildren` 处理缺失数据
- 零运行时依赖，不引入 react-dnd
- Bundle 仅为 react-arborist 的一半

**结论：选用 react-complex-tree（推荐 ✅）**

- 查看体验好（语法高亮、行号），编辑体验完整（括号匹配、搜索替换、自动缩进）
- 首屏零负担，编辑按需加载

### 3.2 后端 API 设计

```
REST API:
  GET    /api/projects/{id}/fs/tree?path=&depth=1    # 目录树（含文件+目录，懒加载单层）
  GET    /api/projects/{id}/fs/read?path=             # 读取文件内容
  GET    /api/projects/{id}/fs/stat?path=             # 文件元信息（大小、类型、修改时间）
  PUT    /api/projects/{id}/fs/write                  # 写入文件内容（需 workspace lease）
  POST   /api/projects/{id}/fs/mkdir                  # 创建目录（需 workspace lease）
  DELETE /api/projects/{id}/fs/remove?path=           # 删除文件/目录（需 workspace lease）
  POST   /api/projects/{id}/fs/rename                 # 重命名（需 workspace lease）
  POST   /api/projects/{id}/fs/search?query=&path=    # 搜索文件名（模糊匹配）
```

**API 设计要点：**

- **统一挂在 `/api/projects/{id}/fs/` 下**：前端不需要关心 runner 类型，后端根据项目的 `runnerID` 自动分发到 `LocalFilesystem` 或 `SFTPFilesystem`
- **读取操作无需 workspace lease**：运行中的 AI agent 可能正在修改文件，但用户查看文件内容不应被阻断
- **写入操作需要 workspace lease**：与现有 Git 操作一致，运行中返回 409，前端显示"AI 运行中，文件编辑已锁定"
- **路径安全**：所有路径必须通过 `allowedPath`（本地）或 `remotePathWithinRoot`（远程）校验
- **Runner 离线处理**：SSH runner 断开时返回结构化错误 `{ "error": "runner_offline", "runnerId": "ssh-xxx" }`，前端显示"连接已断开"提示

### 3.3 Filesystem 接口抽象

```go
// Filesystem 统一抽象，本地和远程各实现一个
type Filesystem interface {
    // 读取操作（无需 workspace lease）
    ReadDir(ctx context.Context, path string) ([]FileEntry, error)
    ReadFile(ctx context.Context, path string) ([]byte, error)
    Stat(ctx context.Context, path string) (FileInfo, error)
    Search(ctx context.Context, rootPath, query string) ([]FileEntry, error)

    // 写入操作（需 workspace lease，由 handler 层检查）
    WriteFile(ctx context.Context, path string, content []byte) error
    Mkdir(ctx context.Context, path string) error
    Remove(ctx context.Context, path string) error
    Rename(ctx context.Context, oldPath, newPath string) error
}

type FileEntry struct {
    Name    string `json:"name"`
    Path    string `json:"path"`
    IsDir   bool   `json:"isDir"`
    Size    int64  `json:"size,omitempty"`
    ModTime string `json:"modTime,omitempty"`
}

type FileInfo struct {
    Name    string `json:"name"`
    Path    string `json:"path"`
    IsDir   bool   `json:"isDir"`
    Size    int64  `json:"size"`
    ModTime string `json:"modTime"`
    Mode    string `json:"mode"`     // 文件权限，如 "0644"
    IsText  bool   `json:"isText"`   // 是否为文本文件
    MimeType string `json:"mimeType"` // MIME 类型，如 "image/png"
}
```

### 3.4 SFTP 持久化 Session

当前 `sshClient.readDir()` 每次新建 SFTP client 再关闭，握手开销约 50-100ms。文件树浏览需要频繁读取目录，必须复用 SFTP session：

```go
type sshClient struct {
    // ... 现有字段 ...
    sftpClient *sftp.Client   // 持久化 SFTP 客户端（懒初始化）
    sftpMu     sync.Mutex     // 保护 sftpClient
}

func (c *sshClient) getSFTPClient(ctx context.Context) (*sftp.Client, error) {
    c.sftpMu.Lock()
    defer c.sftpMu.Unlock()

    if c.sftpClient != nil {
        // 测试连接是否仍可用
        if _, err := c.sftpClient.Stat("."); err == nil {
            return c.sftpClient, nil
        }
        // 连接失效，关闭旧的
        c.sftpClient.Close()
        c.sftpClient = nil
    }

    // 确保 SSH 连接可用
    if err := c.connect(ctx); err != nil {
        return nil, err
    }

    client, err := sftp.NewClient(c.client)
    if err != nil {
        return nil, fmt.Errorf("创建 SFTP 客户端失败：%w", err)
    }
    c.sftpClient = client
    return c.sftpClient, nil
}
```

SFTP client 本身是线程安全的（内部有 mutex），可安全并发复用。SSH 连接断开重连时需重新创建 SFTP client。

### 3.5 大文件与二进制文件处理

| 文件类型 | 大小 | 处理策略 |
| --- | --- | --- |
| 文本文件 | ≤ 1MB | 正常读取，prism/CodeMirror 渲染 |
| 文本文件 | 1MB - 10MB | 读取前提示"大文件，加载可能较慢"，加载后 CodeMirror 只读模式 |
| 文本文件 | > 10MB | 拒绝加载，显示元信息 + 下载按钮 |
| 图片文件 | 任意 | 代理读取，`<img>` 标签预览 |
| 其他二进制 | 任意 | 仅显示元信息（大小/类型/修改时间）+ 下载按钮 |

**文本/二进制判断**：通过扩展名映射 + 前 512 字节检测 NULL 字节（与 Git 的 heuristic 一致）。

**图片代理 API**：

```
GET /api/projects/{id}/fs/raw?path=  # 原始文件内容（用于 <img src> 引用）
```

仅对图片类型（png/jpg/jpeg/gif/svg/webp/ico）响应，其他类型返回 415。

### 4.4 文件查看/编辑器设计

**双模式渲染：**

```typescript
function FileEditor({ path, content, readOnly }: Props) {
  const [editing, setEditing] = useState(false);
  const [EditorModule, setEditorModule] = useState(null);

  const enterEditMode = async () => {
    // 懒加载 CodeMirror
    const mod = await import("@uiw/react-codemirror");
    setEditorModule(mod);
    setEditing(true);
  };

  if (!editing) {
    // 只读模式：prism-react-renderer 语法高亮
    return (
      <div className="file-viewer">
        <Highlight theme={themes.vsDark} code={content} language={lang}>
          {({ style, tokens, getLineProps, getTokenProps }) => (
            <pre style={style}>
              {tokens.map((line, i) => (
                <div {...getLineProps({ line, key: i })}>
                  {line.map((token, j) => (
                    <span {...getTokenProps({ token, key: j })} />
                  ))}
                </div>
              ))}
            </pre>
          )}
        </Highlight>
        {!readOnly && <button onClick={enterEditMode}>编辑</button>}
      </div>
    );
  }

  // 编辑模式：CodeMirror 6（已懒加载）
  return <EditorModule.default value={content} language={lang} onChange={handleChange} />;
}
```

```typescript
  }

  if (!fileInfo.isText) {
    // 二进制文件：显示元信息 + 下载按钮
    return (
      <div className="binary-file-info">
        <p>📄 {fileInfo.name}</p>
        <p>类型：{fileInfo.mimeType || "未知"}</p>
        <p>大小：{formatSize(fileInfo.size)}</p>
        <p>修改时间：{fileInfo.modTime}</p>
        <button onClick={download}>下载</button>
      </div>
    );
  }

  // 文本文件：查看/编辑器
  return <TextFileEditor ... />;
```

### 5.1 LocalFilesystem 实现

```go
type LocalFilesystem struct {
    allowedRoot string // 允许的根路径，与现有 allowedPath 一致
}

func (fs *LocalFilesystem) ReadDir(ctx context.Context, path string) ([]FileEntry, error) {
    absPath, err := fs.allowedPath(path) // 复用现有路径校验
    if err != nil {
        return nil, err
    }
    entries, err := os.ReadDir(absPath)
    if err != nil {
        return nil, err
    }
    var result []FileEntry
    for _, entry := range entries {
        info, _ := entry.Info()
        result = append(result, FileEntry{
            Name:    entry.Name(),
            Path:    filepath.Join(path, entry.Name()),
            IsDir:   entry.IsDir(),
            Size:    info.Size(),
            ModTime: info.ModTime().Format(time.RFC3339),
        })
    }
    return result, nil
}

func (fs *LocalFilesystem) ReadFile(ctx context.Context, path string) ([]byte, error) {
    absPath, err := fs.allowedPath(path)
    if err != nil {
        return nil, err
    }
    // 大小检查：超过 10MB 拒绝
    info, err := os.Stat(absPath)
    if err != nil {
        return nil, err
    }
    if info.Size() > 10*1024*1024 {
        return nil, fmt.Errorf("文件过大（%d 字节），最大支持 10MB", info.Size())
    }
    return os.ReadFile(absPath)
}
```

### 5.2 SFTPFilesystem 实现

```go
type SFTPFilesystem struct {
    client   *sshClient // 复用现有 SSH 客户端（含持久化 SFTP session）
    rootPath string     // 远程路径沙箱
}

func (fs *SFTPFilesystem) ReadDir(ctx context.Context, path string) ([]FileEntry, error) {
    // 路径校验
    if !fs.remotePathWithinRoot(path) {
        return nil, errors.New("路径超出允许范围")
    }

    sftpClient, err := fs.client.getSFTPClient(ctx) // 持久化 session
    if err != nil {
        return nil, err
    }

    entries, err := sftpClient.ReadDir(path)
    if err != nil {
        return nil, err
    }
    var result []FileEntry
    for _, entry := range entries {
        result = append(result, FileEntry{
            Name:    entry.Name(),
            Path:    filepath.Join(path, entry.Name()),
            IsDir:   entry.IsDir(),
            Size:    entry.Size(),
            ModTime: entry.ModTime().Format(time.RFC3339),
        })
    }
    return result, nil
}
```

### 5.3 Handler 层（读写权限分离）

```go
func (s *Server) fsReadFile(w http.ResponseWriter, r *http.Request) {
    projectID := chi.URLParam(r, "projectID")
    path := r.URL.Query().Get("path")

    fs, err := s.getFilesystem(r.Context(), projectID)
    if err != nil {
        writeError(w, 503, err) // runner 离线等
        return
    }

    content, err := fs.ReadFile(r.Context(), path)
    if err != nil {
        writeError(w, 400, err)
        return
    }
    writeJSON(w, 200, map[string]any{"content": string(content)})
}

func (s *Server) fsWriteFile(w http.ResponseWriter, r *http.Request) {
    projectID := chi.URLParam(r, "projectID")

    // 写入操作需要 workspace lease
    release, ok := s.acquireProjectWorkspace(projectID, "fs:"+uuid.NewString())
    if !ok {
        writeError(w, 409, errors.New("project workspace is occupied"))
        return
    }
    defer release()

    fs, err := s.getFilesystem(r.Context(), projectID)
    if err != nil {
        writeError(w, 503, err)
        return
    }

    var req struct {
        Path    string `json:"path"`
        Content string `json:"content"`
    }
    if !decode(w, r, &req) {
        return
    }

    // 原子写入：先写临时文件再 rename
    if err := fs.WriteFile(r.Context(), req.Path, []byte(req.Content)); err != nil {
        writeError(w, 400, err)
        return
    }
    writeJSON(w, 200, map[string]string{"status": "ok"})
}
```

### 5.4 Filesystem 工厂

```go
func (s *Server) getFilesystem(ctx context.Context, projectID string) (Filesystem, error) {
    project, err := s.getProject(ctx, projectID)
    if err != nil {
        return nil, err
    }

    if project.RunnerID == "wsl-local" || project.RunnerID == "" {
        return &LocalFilesystem{allowedRoot: s.config.AllowedRoot}, nil
    }

    // SSH runner
    runner, ok := s.runnerRegistry.get(project.RunnerID)
    if !ok {
        return nil, errors.New("runner offline")
    }
    sshRunner, ok := runner.(*sshRunner)
    if !ok {
        return nil, errors.New("runner is not SSH type")
    }
    return &SFTPFilesystem{client: sshRunner.client, rootPath: sshRunner.rootPath}, nil
}
```

### 5.5 文本/二进制检测

```go
// isTextFile 判断文件是否为文本文件
// 通过扩展名映射 + 前 512 字节检测 NULL 字节
func isTextFile(name string, content []byte) bool {
    // 已知二进制扩展名
    binaryExts := map[string]bool{
        ".png": true, ".jpg": true, ".jpeg": true, ".gif": true,
        ".svg": true, ".webp": true, ".ico": true, ".pdf": true,
        ".zip": true, ".tar": true, ".gz": true, ".exe": true,
        ".woff": true, ".woff2": true, ".ttf": true, ".eot": true,
        ".mp3": true, ".mp4": true, ".wav": true, ".avi": true,
    }
    ext := strings.ToLower(filepath.Ext(name))
    if binaryExts[ext] {
        return false
    }

    // 已知文本扩展名
    textExts := map[string]bool{
        ".ts": true, ".tsx": true, ".js": true, ".jsx": true,
        ".css": true, ".html": true, ".json": true, ".md": true,
        ".go": true, ".py": true, ".rs": true, ".toml": true,
        ".yaml": true, ".yml": true, ".xml": true, ".sh": true,
        ".txt": true, ".sql": true, ".env": true, ".gitignore": true,
    }
    if textExts[ext] {
        return true
    }

    // 未知扩展名：检测前 512 字节
    sample := content
    if len(sample) > 512 {
        sample = sample[:512]
    }
    return !bytes.ContainsRune(sample, 0)
}
```

## 9. 安全考量

| 风险 | 缓解措施 |
| --- | --- |
| 路径穿越攻击 | 本地：复用 `allowedPath()` 校验；远程：复用 `remotePathWithinRoot()` 校验 |
| 恶意大文件读取 | 服务端大小限制（10MB），超出拒绝读取 |
| 未授权写入 | 写入 API 需 workspace lease，运行中禁止写入 |
| Runner 离线 | 结构化错误响应，前端友好提示 |
| 文件内容注入 | 读取文件内容以 `application/json` 返回（base64 编码二进制），不直接 serve 文件 |
| SFTP 连接耗尽 | 持久化单例 session，不每次新建；连接异常时自动重连 |
