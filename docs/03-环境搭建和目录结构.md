## 已建立的目录

```text
auto/
├── docs/                          # 项目文档
├── apps/
│   ├── web/                       # React Web 控制台
│   ├── desktop/                   # 后续桌面客户端
│   ├── control-server/            # Go 控制平面
│   ├── runner/                    # Go 多环境 Runner
│   └── worker/                    # 后续异步工作服务
├── packages/
│   ├── contracts/
│   │   ├── openapi/               # 浏览器 API 契约
│   │   └── proto/                 # Control Server 与 Runner 通信契约
│   ├── domain/                    # 与框架无关的业务规则
│   ├── ui/                        # Web/桌面端复用界面能力
│   ├── sdk/                       # 后续外部集成 SDK
│   └── plugin-kit/                # AI 工具和集成扩展边界
├── infrastructure/                # 本地与后续部署环境定义
├── scripts/                       # 维护脚本
└── data/                          # 本地运行数据，不提交到 Git
```

## 当前限制

- 当前阶段只建立环境与目录，不添加前端、后端或 Runner 的业务代码。
- SQLite 仅用于当前单人、本地 Runner 阶段；多人、远程 Runner 或高并发队列出现后迁移 PostgreSQL、Redis 和对象存储。
- Go 模块路径取决于最终 Git 远程仓库地址，因此暂不创建 `go.mod` 或 `go.work`。
