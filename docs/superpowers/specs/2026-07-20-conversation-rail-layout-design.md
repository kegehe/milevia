# 对话页左侧工作栏布局设计

## 目标

优化项目对话页的左侧工作栏和消息工作区：快捷提示词、常用命令按纵向列表显示，不产生横向滚动；在宽屏收紧整个对话画布距浏览器左边缘的外部留白，使消息时间线整体左移，同时保留左侧工作栏现有的内容宽度和右侧后续扩展空间。

## 范围

- 桌面端保留左侧工作栏约 300px 的可读宽度，不压缩快捷项或任务队列。
- 宽屏下“常用提示词”和“常用命令”共享一个两列网格。标题与第 N 条快捷项占用同一网格行，保证两列文字和按钮的行高对齐；缺少快捷项的一侧留空，新增命令只在命令列向下追加。
- 窄屏下解除共享行和列定位，按 DOM 顺序显示全部提示词后再显示全部命令。标签文字可在按钮内折行，移除横向滚动条。
- 宽屏对话画布不再在 1280px 容器内居中；改为从固定、较小的页面左内边距开始，使左栏与消息时间线一起左移。主区继续自适应占用其余宽度，右侧保留空白以容纳后续内容。
- 无论断点如何，每个分组内的快捷项都保持纵向排列；既有任务抽屉行为不改变。

## 非目标

- 不修改快捷项的发送、变量、编辑、禁用逻辑。
- 不调整任务队列的数据、状态、筛选或下发流程。
- 不新增右侧面板或改变消息、输入框的功能。

## 实现边界

仅调整 `apps/web/src/conversation.css` 的布局规则。宽屏通过 `display: contents` 让两个分组的标题和条目参与同一个父网格；窄屏恢复分组容器。对话画布、快捷行和输入框应使用同一组桌面左内边距，避免时间线与输入区错位。中等及小屏断点继续以现有单栏规则优先，且不允许由快捷项容器产生水平滚动。

## 验证

- 前端 TypeScript 和 Vite 生产构建通过。
- 宽屏下左侧工作栏距窗口左边缘的留白明显小于当前居中布局，工作栏宽度保持不变。
- 宽屏下常用提示词和常用命令的标题及对应第 N 条快捷项共享行高，无水平滚动容器。
- 窄屏下快捷项先显示全部提示词后显示全部命令，不造成页面或工作栏的横向溢出。
