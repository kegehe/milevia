# 对话页实时上下文用量显示设计

## 目标

在桌面端对话页底部和“使用状态”弹窗中持续显示最近一次可信上下文快照的已用 Token、上下文窗口和占用百分比。上下文快照只使用主 Agent 单次请求的完整输入 Token（包含缓存读取和缓存创建），不把 Run 的累计输入 Token 当作上下文占用。

## 方案

保留现有 `usage.updated` WebSocket 事件刷新链路，并在当前 Run 运行期间增加每秒最多一次的 `/api/conversations/{id}/usage` 兜底刷新。定时器只在 Run 存在时启动，清理时停止；每次刷新完成前不启动下一次请求，避免网络较慢时请求重叠。底部状态和弹窗继续读取同一个 `usage` 状态，因此数据和百分比保持一致。

## 状态与边界

- 有上下文 Token和窗口时显示 `已用 / 窗口 (百分比)`。
- 只有 Token 没有窗口时显示已用 Token，并保留“上下文窗口不可用”的语义，不计算伪造百分比。
- 尚未收到可信快照时显示“上下文计算中”；Run 结束仍没有快照时显示“上下文暂不可用”。
- 百分比限制在 100%，颜色继续沿用 normal/warning/danger 阈值。

## 验证

验证上下文格式化函数、运行期间兜底刷新存在且只在 Run 活跃时生效，并运行现有 Web 前端测试及控制服务用量测试。
