# 优化建议新增可清理项类型

## 目标

在现有优化建议扫描的“查找类型”中增加“可清理项”，用于识别项目中不必要的文件、目录、构建产物、重复资源、不可达代码和死逻辑。扫描只读，不直接删除或修改项目文件；用户确认后沿用现有流程转成任务。

## 方案

扩展现有 `InsightType` 枚举，新增 `cleanup`。后端扫描请求、AI prompt、两轮核验、去重入库和任务转换继续复用现有协议。前端同步扩展类型标签、图标、排序、筛选、统计和编辑下拉框。

未知类型继续按现有规则回退到 `optimization`，确保历史数据和旧模型输出兼容。清理建议的 `fileHint` 指向证据位置，转任务时保留“先人工确认再删除或重构”的要求。

## 验证

增加前端类型模型测试，以及后端 prompt 类型清单测试，验证 `cleanup` 能被选择、生成、筛选和统计，并确保旧类型行为不变。
