# 自动开发项目方向

> 日期：2026-07-17

## 项目介绍

这是一个聚合和管理多个软件项目的自动开发平台。

用户可以选择本地项目目录，将其加载到平台中作为一个项目进行管理。在项目中，用户创建开发任务并下发给 AI 编码工具执行，例如 Claude Code、Codex CLI 或后续接入的其他 CLI。平台负责展示 AI 开发的完整过程，并保留任务结果，帮助用户以半自动方式持续迭代项目。

## 希望解决的问题

当同时维护多个项目时，开发任务、AI 对话、代码修改和后续处理往往分散在不同目录和终端中，难以统一查看和管理。

这个项目希望提供一个统一入口，让用户知道：

- 当前管理了哪些项目；
- 每个项目有哪些开发任务；
- AI 正在做什么，已经修改了什么；
- 任务最终是否完成，以及是否需要继续处理。

## 核心流程

```text
选择项目目录
-> 加载项目
-> 创建任务
-> 输入任务要求
-> 选择 AI 工具并下发
-> 查看 AI 开发过程
-> 查看代码修改和任务结果
-> 决定继续迭代、接受或驳回
```

例如，用户在当前项目中创建任务：“为当前项目的侧边栏添加一个 xxtab”。任务下发后，AI 在项目中进行开发；用户可以在平台中看到 AI 的对话、执行过程、文件修改和最终结果。

## 当前想到的功能

- 加载和管理本地项目目录；
- 项目列表和项目基本状态；
- 在项目内创建、查看和管理开发任务；
- 选择 Claude Code、Codex CLI 或其他 AI 开发工具执行任务；
- 实时查看 AI 对话、操作过程和代码变更；
- 查看任务结果，并支持继续、停止、重新下发或人工确认；
- 后续视实际使用需要，再逐步补充分支管理、部署、AI 使用统计等能力。

## 当前原则

- 先把“加载项目 -> 下发任务 -> 查看过程 -> 查看结果”的基本体验做好；
- 功能根据真实使用过程逐步增加，不预先假设所有能力都需要；
- AI 负责执行开发工作，用户始终保留任务判断和结果确认权。
