# CLI 与附件续审

在第 61 号复查记录的基础上继续检查附件上传、SSH 分流输出、跨端模型目录和 WSL 探测超时。本轮修改保留工作区，没有提交或发布。

## 新确认的问题与修复

1. **局域网 HTTP 页面无法上传附件。** 上传目录直接调用安全上下文才提供的 crypto.randomUUID。新增无 crypto / 无 randomUUID 回归，修复前报 TypeError；现在使用非认证用途的备用目录 ID，文件写入仍由 createOnly 防止覆盖。手机浏览器夹具主动移除 randomUUID 并验证备用路径。
2. **SSH 分流输出在大量 stderr 下阻塞。** 两条 Separate 方法先读完 stdout 才读 stderr，4 MiB stderr 可以堵住 SSH 的共享窗口。带 stdin 和不带 stdin 的真实 SSH 传输回归均在修复前超时。现在统一实现，由 ssh.Session 并发排空两条流；stdout 保留原上限加一个溢出字节，stderr 最多保留 64 KiB。保留工作区 Start / Wait / Close 跟踪、原始退出码与取消语义。
3. **跨端模型探测在收齐输出后才检查大小，且 SSH 的 stderr 污染模型 JSON。** 新增可选的有界 shell 探测能力，SSH、WSL 都在读取过程中限制缓冲区，并将诊断流与结构化 stdout 分离。仅在探测成功且未超限时接受模型列表；仍使用实际 runner、原生 PATH、项目工作目录和原有命令别名。未实现该可选能力的适配器安全退回手动模型输入，不使用无界通道。SSH 警告加合法 JSON 的回归在修复前返回空列表。
4. **WSL 路径发现不服从请求预算。** 初次实际 WSL 输出测试等待 Node 路径发现约 10 秒后失败，模型探测自身只有 8 秒预算。路径发现继续在后台共享并填充缓存，各等待者独立响应取消；模型探测、普通探测和管理脚本接入带上下文的 PATH 构造。Node 路径发现自身使用有界进程探针，限制输出和管道收尾。受控回归验证等待途中取消及时返回，后续请求仍能使用共享发现结果。
