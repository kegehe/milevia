# 12-项目启动停止功能

> 日期: 2026-07-23
> 状态: 设计阶段（已通过代码级审查）

## 1. 需求背景

用户加载项目后，经常需要在本地调试运行。目前系统只支持通过 Claude Code 执行 AI 任务，不支持手动启动项目自身的开发服务器（如 `npm run dev`、`go run .` 等）。

期望功能：
- 手动为项目配置启动目录和启动命令
- 在项目页面上执行启动、停止、重启操作
- 实时显示启动过程日志和运行状态
- 支持查看运行状态（运行中/已停止/已崩溃）

## 2. 现有架构分析

### 2.2 审查中发现的问题及修正

在初始设计后进行了代码级审查（逐文件对比 app.go、claude_runner.go、process_unix.go、App.tsx、GitWorkbench.tsx），发现以下问题并已在方案中修正：

| # | 问题 | 严重度 | 修正方式 |
|---|------|--------|---------|
| 1 | **Close() 未停止项目运行进程**：现有 `Close()` 只停止 Claude Code runs/sessions。如果启动了项目开发服务器，control-server 退出时进程会成为孤儿进程 | **高** | Close() 中遍历 `runManagers`，调用每个 runner 的 Stop() |
| 2 | **WS 在 runner 不存在时返回 404**：进程未启动时用户无法连接 WebSocket。用户可能想先打开面板、连接 WS，然后点启动 | **中** | WS subscriber 管理移到 Server 层（`runLogSubscribers map[projectID]map[*websocket.Conn]*subscriber`），与 projectRunner 生命周期解耦。即使进程未运行也能建立 WS 连接 |
| 3 | **Restart 的 Stop+Start 竞态**：Stop 有 5s 超时强制 kill，但 Start 可能在进程真正退出前执行，端口可能未释放 | **中** | projectRunner 增加 `exitChan chan struct{}`，进程退出 goroutine 关闭此 channel。Restart 在 Start 前等待 `<-exitChan` |
| 4 | **start API 临时 workDir 可能路径逃逸**：用户传入 `../../../` 可逃逸出项目目录 | **高** | 校验 workDir 不包含 `..`，且 `filepath.Join(projectPath, workDir)` 结果必须在 projectPath 内 |
| 5 | **WebSocket 写入未加锁**：方案中发送历史日志和实时日志可能并发写入同一个 WS 连接 | **中** | 复用现有 `subscriber.writeMu` 模式（与 `appendEvent` 一致），所有 WriteMessage 前加锁 |
| 6 | **进程崩溃前端无感知**：如果进程被 OOM kill 或 segfault，WS 只收到一个 exit 消息，如果 WS 恰好断开就不知道了 | **中** | 前端 10s 轮询 `/api/projects/{id}/run/status`，作为 WS 的兜底机制 |
| 7 | **命令需要 shell 解析**：`exec.Command("npm", "run", "dev")` 不支持管道、重定向等 shell 特性 | 低 | 使用 `exec.Command("sh", "-c", command)` 执行，文档注明 |
| 8 | **ringBuffer.Recent() 并发 Append 时返回不一致**：如果在遍历 entries 时 Append 修改了 head/size，结果可能包含脏数据 | 低 | Recent() 已在锁内操作，但如果 entries 元素是引用类型会有问题。LogEntry 是值类型，安全 |

### 2.3 与现有功能的区别

这个功能与现有的 Claude Code Runner **完全不同**：

| 维度 | Claude Code Runner | 项目启动服务 |
|------|-------------------|-------------|
| 目的 | 执行 AI 编码任务 | 启动开发服务器 |
| 生命周期 | 单次 Run / 持久 Session | 长期运行直到手动停止 |
| 输入 | stream-json 消息 | 无输入（stdin 关闭） |
| 输出 | stream-json 结构化事件 | 非结构化 stdout/stderr 文本日志 |
| 并发 | 工作区租约互斥 | 独立，不影响 Claude 运行 |
| 与 conversation 关系 | 强绑定 | 与 conversation 无关，与 project 绑定 |

```go
// projectRunner 管理一个项目的运行进程
type projectRunner struct {
    projectID  string
    workDir    string   // 相对于项目根路径
    command    string
    envVars    map[string]string

    cmd        *exec.Cmd
    ctx        context.Context
    cancel     context.CancelFunc

    // 日志环形缓冲区
    logBuf     *ringBuffer     // 保留最近 10000 行

    // 状态
    status     RunStatus       // stopped/starting/running/stopping/failed
    startedAt  time.Time
    pid        int
    exitCode   int             // 仅在 stopped/failed 时有效
    exitChan   chan struct{}   // 进程退出通知（close 表示已退出）

    mu         sync.RWMutex
}

// 注意：WebSocket 订阅者管理在 Server 层，不在 projectRunner 层
// 原因：即使进程未启动，用户也需要连接 WS 等待日志
// Server 中维护: runLogSubscribers map[string]map[*websocket.Conn]*subscriber
// key 为 projectID，与 projectRunner 生命周期解耦

type RunStatus string
const (
    RunStatusStopped  RunStatus = "stopped"
    RunStatusStarting RunStatus = "starting"
    RunStatusRunning  RunStatus = "running"
    RunStatusStopping RunStatus = "stopping"
    RunStatusFailed   RunStatus = "failed"
)

type LogEntry struct {
    Timestamp time.Time `json:"timestamp"`
    Stream    string    `json:"stream"`    // "stdout" | "stderr" | "system"
    Text      string    `json:"text"`
}
```

#### 3.4.2 核心逻辑: project_runner.go（修正版）

```go
package app

import (
    "bufio"
    "context"
    "fmt"
    "io"
    "os/exec"
    "path/filepath"
    "strings"
    "sync"
    "syscall"
    "time"
)

// ringBuffer 日志环形缓冲区
type ringBuffer struct {
    entries []LogEntry
    head    int
    size    int
    cap     int
    mu      sync.RWMutex
}

func newRingBuffer(cap int) *ringBuffer {
    return &ringBuffer{
        entries: make([]LogEntry, cap),
        cap:     cap,
    }
}

func (rb *ringBuffer) Append(e LogEntry) {
    rb.mu.Lock()
    defer rb.mu.Unlock()
    rb.entries[rb.head] = e
    rb.head = (rb.head + 1) % rb.cap
    if rb.size < rb.cap {
        rb.size++
    }
}

func (rb *ringBuffer) Recent(n int) []LogEntry {
    rb.mu.RLock()
    defer rb.mu.RUnlock()
    if n > rb.size {
        n = rb.size
    }
    result := make([]LogEntry, n)
    start := (rb.head - n + rb.cap) % rb.cap
    for i := 0; i < n; i++ {
        result[i] = rb.entries[(start+i)%rb.cap]
    }
    return result
}

// broadcast 将日志广播到所有订阅者（在 Server 层实现）
type logBroadcaster func(entry LogEntry)

// projectRunner 项目运行管理器
type projectRunner struct {
    projectID  string
    workDir    string
    command    string
    envVars    map[string]string

    cmd      *exec.Cmd
    ctx      context.Context
    cancel   context.CancelFunc

    logBuf   *ringBuffer
    broadcast logBroadcaster  // 由 Server 注入

    status    RunStatus
    startedAt time.Time
    pid       int
    exitCode  int
    exitChan  chan struct{}   // close 表示进程已退出

    mu        sync.RWMutex
}

// Start 启动进程
func (pr *projectRunner) Start(parentCtx context.Context, projectPath string) error {
    pr.mu.Lock()
    if pr.status == RunStatusRunning || pr.status == RunStatusStarting {
        pr.mu.Unlock()
        return fmt.Errorf("process already running")
    }

    // 计算实际工作目录
    workDir := filepath.Join(projectPath, pr.workDir)
    // 安全检查：确保 workDir 在 projectPath 内
    rel, err := filepath.Rel(projectPath, workDir)
    if err != nil || strings.HasPrefix(rel, "..") {
        pr.mu.Unlock()
        return fmt.Errorf("work directory escapes project path")
    }

    pr.status = RunStatusStarting
    pr.exitChan = make(chan struct{})
    pr.mu.Unlock()

    // 使用 sh -c 执行命令，支持管道、重定向等
    pr.ctx, pr.cancel = context.WithCancel(parentCtx)
    pr.cmd = exec.CommandContext(pr.ctx, "sh", "-c", pr.command)
    pr.cmd.Dir = workDir

    // 设置环境变量
    pr.cmd.Env = os.Environ()
    for k, v := range pr.envVars {
        pr.cmd.Env = append(pr.cmd.Env, k+"="+v)
    }

    // 配置进程组（复用 process_unix.go）
    configureProcessGroup(pr.cmd)

    // 管道读取 stdout/stderr
    stdout, _ := pr.cmd.StdoutPipe()
    stderr, _ := pr.cmd.StderrPipe()

    if err := pr.cmd.Start(); err != nil {
        pr.mu.Lock()
        pr.status = RunStatusFailed
        close(pr.exitChan)
        pr.mu.Unlock()
        return fmt.Errorf("start process: %w", err)
    }

    pr.mu.Lock()
    pr.pid = pr.cmd.Process.Pid
    pr.startedAt = time.Now()
    pr.status = RunStatusRunning
    pr.mu.Unlock()

    // 发送 system 日志
    pr.broadcast(LogEntry{Timestamp: time.Now(), Stream: "system",
        Text: fmt.Sprintf("process started: pid=%d, command=%s", pr.pid, pr.command)})

    // 读取 goroutines
    go pr.readPipe(stdout, "stdout")
    go pr.readPipe(stderr, "stderr")

    // 等待进程结束 goroutine
    go pr.wait()

    return nil
}

// readPipe 读取管道输出并广播
func (pr *projectRunner) readPipe(r io.Reader, stream string) {
    scanner := bufio.NewScanner(r)
    scanner.Buffer(make([]byte, 64*1024), 1024*1024) // 支持长行
    for scanner.Scan() {
        entry := LogEntry{
            Timestamp: time.Now(),
            Stream:    stream,
            Text:      scanner.Text(),
        }
        pr.logBuf.Append(entry)
        pr.broadcast(entry)
    }
}

// wait 等待进程退出
func (pr *projectRunner) wait() {
    err := pr.cmd.Wait()
    pr.mu.Lock()
    exitCode := 0
    if err != nil {
        if exitErr, ok := err.(*exec.ExitError); ok {
            exitCode = exitErr.ExitCode()
        } else {
            exitCode = -1
        }
        pr.status = RunStatusFailed
    } else {
        pr.status = RunStatusStopped
    }
    pr.exitCode = exitCode
    pr.mu.Unlock()

    pr.broadcast(LogEntry{Timestamp: time.Now(), Stream: "system",
        Text: fmt.Sprintf("process exited: code=%d", exitCode)})
    close(pr.exitChan)
}

// Stop 停止进程
func (pr *projectRunner) Stop() error {
    pr.mu.Lock()
    if pr.status != RunStatusRunning {
        pr.mu.Unlock()
        return fmt.Errorf("process not running")
    }
    pr.status = RunStatusStopping
    pr.mu.Unlock()

    pr.broadcast(LogEntry{Timestamp: time.Now(), Stream: "system",
        Text: "stopping process..."})

    terminateProcessGroup(pr.cmd)

    // 等待 5s 优雅退出
    select {
    case <-pr.exitChan:
        // 正常退出
    case <-time.After(5 * time.Second):
        forceTerminateProcessGroup(pr.cmd)
        <-pr.exitChan // 等待强制 kill 生效
    }
    return nil
}

// Restart 重启（修正版：等待退出后再启动）
func (pr *projectRunner) Restart(parentCtx context.Context, projectPath string) error {
    pr.mu.RLock()
    running := pr.status == RunStatusRunning || pr.status == RunStatusStarting
    pr.mu.RUnlock()

    if running {
        if err := pr.Stop(); err != nil {
            return fmt.Errorf("stop before restart: %w", err)
        }
        // exitChan 已在 Stop 中被等待（通过 <-pr.exitChan 或超时后 <-pr.exitChan）
    }

    return pr.Start(parentCtx, projectPath)
}

// StatusSnapshot 返回当前状态快照
func (pr *projectRunner) StatusSnapshot() RunStatusResponse {
    pr.mu.RLock()
    defer pr.mu.RUnlock()
    return RunStatusResponse{
        Status:     pr.status,
        StartedAt:  pr.startedAt,
        PID:        pr.pid,
        ExitCode:   pr.exitCode,
        RecentLogs: pr.logBuf.Recent(200),
    }
}
```

```go
        s.closing = true
```

#### 3.4.4 WebSocket 日志广播（修正版）

```go
func (s *Server) subscribeRunLogs(w http.ResponseWriter, r *http.Request) {
    projectID := chi.URLParam(r, "projectID")

    conn, err := s.upgrader.Upgrade(w, r, nil)
    if err != nil {
        return
    }

    sub := &subscriber{conn: conn}
    s.runLogSubMu.Lock()
    if s.runLogSubscribers[projectID] == nil {
        s.runLogSubscribers[projectID] = map[*websocket.Conn]*subscriber{}
    }
    s.runLogSubscribers[projectID][conn] = sub
    s.runLogSubMu.Unlock()

    defer func() {
        s.runLogSubMu.Lock()
        delete(s.runLogSubscribers[projectID], conn)
        s.runLogSubMu.Unlock()
        conn.Close()
    }()

    // 发送历史日志（如果 runner 存在）
    s.runManagersMu.RLock()
    runner, ok := s.runManagers[projectID]
    s.runManagersMu.RUnlock()
    if ok {
        for _, e := range runner.logBuf.Recent(200) {
            sub.writeMu.Lock()
            conn.WriteJSON(e)
            sub.writeMu.Unlock()
        }
    }

    // 读取循环（检测断开）
    for {
        if _, _, err := conn.ReadMessage(); err != nil {
            return
        }
    }
}

// broadcastRunLog 广播日志到所有订阅者（注入到 projectRunner）
func (s *Server) broadcastRunLog(projectID string, entry LogEntry) {
    s.runLogSubMu.Lock()
    subs := s.runLogSubscribers[projectID]
    // 复制一份避免长时间持锁
    conns := make([]*subscriber, 0, len(subs))
    for _, sub := range subs {
        conns = append(conns, sub)
    }
    s.runLogSubMu.Unlock()

    for _, sub := range conns {
        sub.writeMu.Lock()
        sub.conn.WriteJSON(entry)
        sub.writeMu.Unlock()
    }
}
```

### 3.6 安全考虑

1. **路径隔离**: workDir 必须不包含 `..`，最终绝对路径必须在 projectPath 内
2. **命令执行**: 使用 `sh -c` 执行，第一版信任用户输入（因为这是本地工具，浏览器不直接接触文件系统）
3. **进程组隔离**: 复用 `configureProcessGroup` 设置独立进程组，Stop 时可以杀掉整个进程树
4. **孤儿进程**: Close() 时遍历停止所有 projectRunner，防止孤儿进程

## 6. 关键技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 日志存储 | 内存环形缓冲区 (10000行) | 不需要持久化历史日志，节省数据库开销 |
| 日志传输 | WebSocket + HTTP 轮询兜底 | 实时推送 + 防丢消息 |
| WS 订阅管理 | Server 层（按 projectID） | 与 runner 生命周期解耦，进程未启动也可连接 |
| 进程模型 | 每个项目最多一个进程 | 简化设计，符合"启动开发服务器"的场景 |
| 配置存储 | SQLite | 持久化启动配置，重启后保留 |
| 前端展示 | 弹窗面板 | 复用已有模式，不影响主界面 |
| 优雅终止 | SIGTERM → 5s → SIGKILL | 复用 process_unix.go 的逻辑 |
| 命令执行 | `sh -c` | 支持管道、重定向等 shell 特性 |
| 路径安全 | filepath.Rel 检查 | 防止 workDir 逃逸项目路径 |
| 退出通知 | exitChan (chan struct{}) | Restart 等待进程完全退出后再启动 |
